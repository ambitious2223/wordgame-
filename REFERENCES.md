# Similar Games References

## Your Game Concept
**TikTok Arabic Word Guessing Game**
- Streamer shows scrambled letters
- Players guess words from those letters
- 15-second rounds
- Score based on letter values

---

## Similar Games

### 1. Scrabble
- **Type:** Board game
- **Mechanic:** Form words from letter tiles on a board
- **Scoring:** Each letter has point value (1-10 pts)
- **Relevance:** Letter value system, word formation

### 2. Wheel of Fortune
- **Type:** TV game show
- **Mechanic:** Guess letters to reveal hidden word
- **Scoring:** Prize money for correct guesses
- **Relevance:** Letter reveal, word guessing, live audience

### 3. Wordle
- **Type:** Mobile/web game
- **Mechanic:** Guess 5-letter word in 6 tries
- **Scoring:** Win/lose only
- **Relevance:** 5-letter format, daily puzzles, social sharing

### 4. Countdown (UK)
- **Type:** TV game show
- **Mechanic:** Form longest word from 9 random letters
- **Scoring:** Points for word length
- **Relevance:** Letter scrambling, time pressure, live competition

### 5. Lingo
- **Type:** TV game show
- **Mechanic:** Guess 5-letter word, get letter hints
- **Scoring:** Points for correct guesses
- **Relevance:** Letter hints, word guessing, live play

### 6. Bananagrams
- **Type:** Board game
- **Mechanic:** Build words from letter tiles speed
- **Scoring:** First to finish wins
- **Relevance:** Speed word building, letter pool

## Your Game Flow

```
1. Show 5 scrambled Arabic letters
2. Start 15-second timer
3. Players guess words in TikTok chat
4. Correct guess = letter values summed
5. Multiple words per round = multiplier bonus
6. Highest total score wins
```
